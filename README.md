# pegsolitaire 孔明棋

英式孔明棋（English peg solitaire）终端版：7×7 十字棋盘，中央留空。
跳过一颗相邻棋子落到空位，吃掉被跳过的棋子——目标是最后只剩一颗棋子。

```bash
python -m pegsolitaire          # 交互游玩
python -m pegsolitaire --demo   # 播放 31 步标准解法演示
```

## 玩法

棋盘坐标是列 A–G、行 1–7。输入如 `D4 D6` 表示把 D4 的棋子跳到 D6：

- 必须跳过一颗**相邻**（上下左右，不能斜跳）的棋子；
- 落点必须是空位，且起点、被跳的棋子、落点都在棋盘上；
- 每走一步吃掉一颗棋子，`u` 悔棋，`q` 退出。

## 设计取舍

- `--demo` 内嵌的 31 步解法是公开发表的英式棋盘经典解法（中央开局、中央收官），
  已用本程序的走子引擎逐一校验：31 步全部合法、终局恰好剩 1 子。
  （曾尝试用 DFS 现场求解生成，但朴素回溯在 90 秒内找不到解，改用已发表的解法并做程序验证。）
- 悔棋用栈记录每次吃掉的棋子位置，任意步数可退。
- 无自动求解器：棋盘状态空间虽小，但“现场求解最优步数”不在本项目范围。

## 已知局限

- 只有英式棋盘（7×7 十字），无法式/德式变体。
- 交互是行输入模式，每步需回车；不支持方向键。
- 无最佳成绩记录。
